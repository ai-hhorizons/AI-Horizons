# AI-Horizons
AI Horizons – ProductHunt style AI tools directory

## SEO setup

- Canonical URL is set to `https://ai-hhorizons.github.io/AI-Horizons/` (GitHub Pages).
  If you use a custom domain, replace that URL in `index.html`, `robots.txt` and `sitemap.xml`.
- After deploying, submit `sitemap.xml` in Google Search Console and Bing Webmaster Tools.
- Update `<lastmod>` in `sitemap.xml` whenever content changes.
